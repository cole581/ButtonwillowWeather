Observed: WeatherXM station at L62 (public cell endpoint), sampled every 15 minutes by a GitHub Actions workflow. Forecast: NWS hourly forecast graph (same NDFD grid, via api.weather.gov gridpoint data), snapshotted every hour. “Forecast lead” picks, for each observation, the newest forecast issued at least that many hours earlier, so you can see how accuracy changes with lead time. “Latest” uses the newest forecast fetched before the observation. Gust direction is not reported separately by either source; the station’s wind direction is used. Observed hourly precipitation is the change in the station’s accumulated-rain counter between samples; NWS 6-hour QPF is spread evenly across its hours. NWS does not forecast pressure, so that plot is observed only; the station reports pressure adjusted to sea level (≈1013 hPa scale), which is close to, but not the same as, an altimeter setting. Shaded plot backgrounds mark daylight (sunrise to sunset at L62).
